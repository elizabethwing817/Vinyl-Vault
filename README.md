# Vinyl Vault

Vinyl Vault is a personal vinyl collection and listening history database project designed to organize detailed information about a record collection while tracking when records are played.

## About the Project

I started Vinyl Vault because I wanted a way to manage my vinyl collection while also keeping a listening history. Existing music cataloging tools provide useful collection information, but I wanted to build a system tailored to the information I personally want to track.

Vinyl Vault is also an ongoing portfolio project where I can apply and expand my skills in backend development, database design, Python, and SQL.

## Planned Features

- Store and manage artists, albums, and tracks
- Track individual vinyl releases and catalog numbers
- Record pressing and edition information
- Track record condition
- Maintain a listening history
- Record the last time an album was played
- Search and browse the collection
- Distinguish manually entered records when needed

## Database Design

The database is being designed around related data including:

- Artists
- Albums
- Tracks
- Vinyl releases
- Listening history

The structure will use relationships between these records to reduce duplicate data and make collection information easier to manage.
